# Project documentation

This directory contains the operational and development documentation that is useful beyond the main project overview.

- [Getting started](getting-started.md): install, configure, run, and manage the monitor.
- [Testing and packaging](testing.md): run the test suite, exercise the CLI, and validate the npm tarball.
- [GitHub Actions](github-actions.md): understand CI, release tags, and npm publishing.
- [Architecture](architecture.md): understand the Electron process, monitor loop, actions, state, logs, and LaunchAgent.
- [JSDoc standard](jsdoc.md): required API documentation structure and examples.

The canonical user-facing overview remains in the root [README](../README.md). Keep these documents synchronized with behavior, defaults, commands, and release procedures.
